# Roadmap

## Near-term
- Improve aggregator collectors (Indeed/LinkedIn/Glassdoor/Wellfound/Levels)
- Expand role packs (Design, Data, Security, Hardware, Sales, etc.)
- Add remote and salary filters
- Improve ranking with hybrid signals and recency

## Mid-term
- Resume tailoring and job-specific matching
- Alerts (email/slack) for new matches
- Application tracking and status reporting

## Long-term
- Community-maintained job source catalog
- Hosted version for daily updates
- API for third-party integrations
